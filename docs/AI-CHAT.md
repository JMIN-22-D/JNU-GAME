# 제록이 대화에 AI 붙이기

지금 제록이는 **기기 안에서 도는 규칙 기반 대화**입니다. 인터넷 없이도 되고,
말이 밖으로 나가지 않아요. 34개 주제 · 91문장 기준 100% 매칭을 확인해 뒀습니다.

여기에 생성형 AI를 붙이면 정해진 답이 아니라 그때그때 다른 말을 합니다.
아래 순서대로 하면 **무료로** 됩니다. 5분쯤 걸려요.

---

## 왜 앱에 키를 바로 못 넣나

이 앱은 `jeju_life_support_portal (6).html` **파일 하나**로 돌아갑니다.
그 안에 API 키를 적으면 파일을 받은 사람 누구나 키를 꺼내 쓸 수 있어요.
요금이 새거나 계정이 정지됩니다.

그래서 **키를 들고 있는 작은 중계 서버**를 하나 두고, 앱은 그 주소로만
말을 겁니다. 중계 서버는 Cloudflare Workers 무료 등급으로 충분합니다
(하루 10만 요청).

```
앱 (키 없음)  →  중계 서버 (키 보관)  →  Gemini API
```

---

## 1. Gemini API 키 받기 (무료)

1. https://aistudio.google.com/apikey 접속
2. 구글 계정으로 로그인 → **Create API key**
3. 나온 키를 복사해 둡니다 (`AIza...` 로 시작)

개인 사용 무료 등급이 있습니다. 신용카드 등록이 필요 없습니다.

## 2. 중계 서버 올리기

1. https://dash.cloudflare.com 가입 (무료)
2. **Workers & Pages → Create → Workers → Create Worker**
3. 이름을 아무거나 정하고 **Deploy**
4. **Edit code** 를 눌러 편집기를 열고, 원래 내용을 전부 지운 뒤
   `tools/jerok-worker.js` 내용을 **통째로 붙여넣기** → **Deploy**
5. **Settings → Variables and Secrets → Add**
   - Type: **Secret**
   - Name: `GEMINI_KEY`
   - Value: 1번에서 받은 키
   - **Deploy** 를 한 번 더 눌러야 반영됩니다

## 3. 허용 주소 맞추기

`tools/jerok-worker.js` 위쪽 `ALLOWED` 에 앱을 여는 주소를 적습니다.
아무 데서나 부를 수 있으면 남이 내 키로 요금을 씁니다.

```js
const ALLOWED = [
    "http://localhost:5173",        // 로컬 테스트
    "https://jmin-22.github.io",    // 깃허브 페이지에 올렸다면
    "null"                          // HTML 파일을 직접 열었을 때
];
```

> `"null"` 은 파일을 더블클릭해서 열 때 필요합니다. 배포용으로만 쓸 거면
> 빼는 편이 안전합니다.

## 4. 앱에 주소 넣기

`www/js/app.js` 에서 이 줄을 찾아 배포된 주소를 넣습니다.

```js
const JEROK_AI_ENDPOINT = "";
```
↓
```js
const JEROK_AI_ENDPOINT = "https://내워커이름.내계정.workers.dev";
```

그리고 다시 빌드합니다.

```bash
powershell -ExecutionPolicy Bypass -File "tools/build.ps1"
```

## 안전장치 — 이 부분이 제일 중요합니다

이 앱은 자살예방이 목적입니다. AI가 위험한 순간에 엉뚱한 말을 하면
안 되기 때문에 **네 겹**으로 막아뒀습니다.

| 순서 | 어디서 | 무엇을 |
|---|---|---|
| 1 | 기기 (`sendChatMessage`) | 위기 표현이면 **AI를 부르지 않고** 109 안내 카드를 띄웁니다 |
| 2 | 중계 서버 | 그래도 넘어온 위기 표현은 서버에서 한 번 더 걸러 냅니다 |
| 3 | 모델 | 시스템 프롬프트로 진단·처방·약 이야기를 막고, 자해 주제는 109 안내만 하게 합니다. Gemini 안전 필터도 켜 둡니다 |
| 4 | 기기 (`askJerok`) | AI가 돌려준 **답변에도** 위기 표현이 섞이면 버리고 직접 만든 답으로 돌아갑니다 |

위기 감지는 28개 표현을 잡고 오탐은 16개 문장 중 0건입니다
(`"과제 못 버티겠다"`, `"배고파 죽겠어"` 같은 건 걸리지 않습니다).

### 그 밖의 보호

- **개인정보를 보내지 않습니다** — 학번·이름은 서버로 안 갑니다. 대화 내용만 갑니다.
- **대화 기록은 최근 6마디만** 들고 다니고, 대화창을 닫으면 지워집니다.
- **7초 안에 답이 없으면** 기다리지 않고 규칙 기반으로 넘어갑니다.
- **세 번 내리 실패하면 2분 쉽니다** — 인터넷이 끊겼을 때 매번 기다리지 않도록.
- **AI를 끄고 싶으면** `JEROK_AI_ENDPOINT` 를 `""` 로 되돌리면 됩니다.
  나머지는 아무것도 안 건드려도 예전처럼 돌아갑니다.

## 붙이지 않는 선택도 괜찮습니다

규칙 기반은 **인터넷 없이 돌고, 말이 기기 밖으로 안 나가고, 예상 못 한
답이 나올 일이 없습니다.** 학생 상담이라는 성격을 생각하면 이게 더 안전한
선택일 수 있어요.

AI를 붙이면 대화가 자연스러워지는 대신, 드물게 어색하거나 엉뚱한 말이
나올 수 있습니다. 학생들에게 배포하기 전에 **직접 여러 상황으로 충분히
말을 걸어보고** 판단해 주세요. 특히 힘든 이야기를 꺼냈을 때 어떻게
반응하는지 확인이 필요합니다.
