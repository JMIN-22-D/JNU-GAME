Node.js + Android Studio 설치 후 안드로이드 빌드로 확인해야 합니다.
확인할 것: 권한 요청 팝업 → 정한 시각에 알림 도착 → 탭하면 앱 열림.

이 앱의 가장 큰 약점은 **학생이 앱 여는 걸 잊는다**는 것. 미션도 병아리도
안 들어오면 의미가 없는데, 지금은 "들어와 주세요"라고 말할 수단이 없음.

- `@capacitor/local-notifications` 사용, 서버 불필요
- 학생이 **알림 시간을 직접 고르고 끌 수 있어야 함**
  (정신건강 앱에서 원치 않는 알림은 역효과가 큼)
- 이미 오늘 목표를 채웠으면 알림을 띄우지 않음
- 웹 브라우저에서는 조용히 아무 일도 하지 않음
- 네이티브 앱으로 가는 실질적 이유가 사실상 이 기능

> 실제 알림 확인은 Node.js + Android Studio 설치 후 안드로이드 빌드가 필요함.

### 2. 제주대 학생상담센터 연결 카드

위기 카드에 109·1393·119는 있는데 **정작 학교 자체 자원으로 가는 길이 없음.**
제록이가 "제주대는 학생상담센터가 무료예요"라고 말만 하고 끝남.

- 전화번호, 예약 링크, 운영 시간, 위치를 카드 하나로
- 109는 낯설고 부담스럽지만 학교 상담센터는 문턱이 훨씬 낮음
- 학생복지과 사업에서 **연계 실적이 잡히는 유일한 창구**
- ⚠️ 실제 연락처·운영시간·예약 링크를 확인해서 알려줘야 함

### 3. 앱 내 피드백 버튼

1차 테스트를 도는데 **여러분에게 돌아오는 정보가 0.**
몇 명이 며칠 썼는지, 어떤 미션을 하는지, 제록이를 쓰긴 하는지 알 수 없음.
사업 결과 보고에 쓸 근거가 없다는 뜻.

- 앱 안에 버튼 → 구글폼 연결, `APP_VERSION` 자동 첨부
- 백엔드도 개인정보 문제도 없는 제일 싼 방법
- ⚠️ 구글폼을 만들어서 URL을 알려줘야 함
- 그 이상(익명 사용 통계)은 **무엇을 보고해야 하는지 먼저 정하고** 최소한만 수집.
  대화 내용 수집은 절대 금지.

### 4. 제록이 AI 연결 — 승인이 먼저

`app.js`의 `JEROK_AI_ENDPOINT`에 터는 이미 닦여 있음(폴백 구조 포함).
Cloudflare Workers에 키 숨긴 프록시 하나면 연결됨.

지금은 정해진 답변을 돌려쓰는 구조라 몇 번만 대화해도 패턴이 보이고,
그 순간 "얘는 그냥 프로그램이구나" 하고 신뢰가 깨짐.

- ⚠️ **자살위험 학생과 LLM이 대화하는 건 가볍게 결정할 일이 아님**
- 위기 감지는 지금처럼 기기에서 **먼저 무조건** 걸리게 유지, AI는 그 뒤에만
- 시스템 프롬프트에 안전 지침 필수
- **학생복지과 + 상담 전문가 검토 승인이 선행.** 기술보다 이게 더 오래 걸림

## 캠퍼스 로드뷰 — 카카오 API 키를 넣어야 켜집니다  ★

산책 탭의 '캠퍼스'는 두 가지 모드로 열립니다.

- **로드뷰** 실제 거리 사진 속을 1인칭으로 걸어다님 (기본)
- **지도** 위에서 내려다보는 지도 (로드뷰가 안 될 때 자동 폴백)

**지금은 키가 없어서 지도 모드만 뜹니다.** 로드뷰를 켜려면:

1. [developers.kakao.com](https://developers.kakao.com) 로그인 → **내 애플리케이션 → 애플리케이션 추가**
2. **앱 → 플랫폼 키 → JavaScript 키** 복사
   - 콘솔 개편으로 앱 키들이 '플랫폼 키' 아래로 묶였습니다.
     예전 문서의 '앱 키' 메뉴는 이제 없습니다.
   - 같은 화면의 REST API 키·네이티브 앱 키는 이 프로젝트에 필요 없습니다.
   - **어드민 키는 별도 메뉴에 있고, 절대 코드에 넣거나 공유하면 안 됩니다.**
3. 같은 화면의 **JavaScript SDK 도메인** 에 아래를 등록
   - 로컬 확인: `http://localhost:5173`
   - 깃허브 테스트: `https://jmin-22.github.io`
   - (`제품 링크 관리`의 '웹 도메인'은 카카오톡 공유용이라 무관합니다)
4. [www/js/campus.js](../www/js/campus.js) 맨 위 `kakaoAppKey: ""` 에 붙여넣기

> ⚠️ `file://` (HTML 더블클릭)로는 로드뷰가 뜨지 않습니다. 도메인이 없어서
> 카카오가 인증을 거부합니다. `tools/serve.ps1` 로 로컬 서버를 띄우고
> `http://localhost:5173` 으로 접속해야 합니다.

무료이고 결제 수단 등록도 필요 없습니다. JavaScript 키는 원래 공개되는
값이라 코드에 그대로 둬도 됩니다 — 도메인 등록으로 보호되는 방식입니다.

### 남은 확인 사항

- [ ] **캠퍼스 안쪽 로드뷰 커버리지.** 로드뷰는 차가 다닌 길만 찍혀 있어서
      건물 사이 보행로는 비어 있을 수 있습니다. 사진이 없는 쪽으로 가면
      "이쪽은 더 갈 수 없어요"가 뜹니다. 실제로 얼마나 다닐 수 있는지는
      키를 넣고 확인해봐야 합니다
- [ ] **네이티브 앱에서의 도메인 문제.** Capacitor 는 출처가
      `capacitor://localhost` 라서 카카오 도메인 등록이 안 먹을 수 있습니다.
      막히면 `capacitor.config.json` 의 `server.hostname` 을 등록한 도메인으로
      맞추거나, 로드뷰는 웹 배포판에서만 쓰는 쪽을 검토해야 합니다
- [ ] **좌표 확인.** 시작점이 `33.4566, 126.5619` 로 넣어둔 값입니다.
      화면에 현재 좌표가 계속 표시되니 원하는 자리로 걸어가서
      `CAMPUS.center` 에 옮겨 적으면 됩니다
- [ ] 로드뷰도 지도도 **인터넷이 있어야** 보입니다
- [ ] `@capacitor/screen-orientation` 을 새로 넣었으므로 `npm install` 필요

**걷기 미션에는 일부러 반영하지 않았습니다.** 그 미션은 학생을 실제로
바깥에 나가게 하려는 것이라 방향키로 완료되면 취지가 사라집니다.
캠퍼스 산책은 코인만 줍니다(80m당 1코인, 1회 최대 30코인).
생각이 다르시면 [campus.js](../www/js/campus.js) 의 `rewardWalk` 를 고치면 됩니다.

## 단일 파일 만들기

`www/` 를 고친 뒤 아래를 실행하면 바탕화면 폴더에 두 파일이 새로 만들어집니다.

```
powershell -File "tools\build.ps1"
```

| 파일 | 용도 |
|---|---|
| `DEMO.html` | 시연용. 데모 패널 + 열자마자 전부 열린 상태 |
| `jeju_life_support_portal (6).html` | 일반 플레이용. 데모 코드 없음 |

둘 다 CSS·JS·이미지를 안에 다 넣어서 **더블클릭만으로 열립니다.** 서버도 인터넷도
필요 없고, USB나 메신저로 보내도 그대로 동작합니다.

오류가 나면 화면 맨 위에 빨간 줄로 내용이 뜹니다(`tools/inject-errbar.js`).
정상일 때는 아무것도 뜨지 않습니다.

> `tools/build.ps1` 은 **순수 ASCII로 유지**해야 합니다. 윈도우 PowerShell 5.1이
> .ps1 을 ANSI로 읽어서, 스크립트 안에 한글을 넣으면 깨져서 파싱 자체가 실패합니다.
> 한글이 들어갈 내용은 `tools/inject-*.js` 쪽에 두세요 (UTF-8로 따로 읽습니다).

## 유지보수 규칙

**CSS나 JS를 고쳐서 배포할 때마다** `index.html`의 `?v=` 숫자와
`app.js`의 `APP_VERSION`을 같이 올릴 것. 안 올리면 이미 방문한 테스터는
계속 옛 화면을 봄.

```
css/style.css?v=0.9.0   js/native.js?v=0.9.0   js/app.js?v=0.9.0
```
