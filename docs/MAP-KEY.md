# 캠퍼스 산책 지도 키 넣기

캠퍼스 산책의 **지도 모드**가 쓰는 타일 이야기입니다.
로드뷰(카카오)는 별개예요.

---

## 왜 바꿔야 하나

원래는 `tile.openstreetmap.org` 를 썼습니다. 그런데 그건 **자원봉사자들이
기부금으로 굴리는 서버**이고, 이용 정책상 앱을 배포해서 쓰는 걸 막고 있어요.

차단은 도메인 단위로 걸립니다. 즉 걸리는 순간 **학생 전원이 동시에**
지도를 못 보게 됩니다. 그래서 키를 받아 쓰는 곳으로 옮깁니다.

---

## 1. 키 받기 (둘 중 하나, 무료)

| | 가입 | 키 위치 | 무료 한도 |
|---|---|---|---|
| **MapTiler** | maptiler.com | Account → Keys | 월 10만 요청 |
| **Mapbox** | mapbox.com | Account → Tokens | 월 20만 요청 |

둘 다 카드 등록 없이 무료 등급으로 시작할 수 있습니다.
아래 사용량 계산을 보면 알겠지만, **어느 쪽이든 넉넉합니다.**

## 2. 앱에 넣기

다시 빌드할 필요 없습니다.

1. 앱 맨 아래 **버전 글자를 1초 안에 다섯 번** 누릅니다
2. `🗺️ 지도 키 설정 필요` 버튼이 나타납니다
3. 제공처 번호(1=MapTiler, 2=Mapbox)를 고르고 키를 붙여넣습니다

넣으면 **타일을 한 장 실제로 받아서 확인**합니다. 키가 틀리면
401/403 을 잡아내서 알려주니, 잘못 넣고 배포할 일은 없습니다.

## 3. ★ 도메인 제한 걸기 (꼭)

키는 앱 파일 안에 들어갑니다. **받은 사람 누구나 꺼내 볼 수 있어요.**
안 걸어두면 남이 내 키로 요청을 쓰고, 한도가 남의 손에 소진됩니다.

- **MapTiler**: Keys → 해당 키 → *Allowed origins* 에 배포 주소 등록
- **Mapbox**: Tokens → 해당 토큰 → *URL restrictions* 에 배포 주소 등록

---

## 사용량 — 생각보다 훨씬 적게 듭니다

돌아다닐 수 있는 범위가 정해져 있어서(±780m), **줌 17 기준 캠퍼스
전체가 56장**입니다. 한 학생이 아무리 오래 걸어도 그 이상은 안 받아요.

예전에는 화면 밖으로 나간 타일을 버렸다가 되돌아오면 다시 받았습니다.
실측으로 **걸음당 2장**, 100걸음이면 200장씩 나갔어요.
지금은 한 번 받은 타일을 계속 들고 있습니다(전부 들고 있어도 2MB 남짓).

| | 학생 1인당 | MapTiler 10만 | Mapbox 20만 |
|---|---|---|---|
| 예전 (100걸음 산책) | 200장 | 500회 | 1,000회 |
| **지금 (최대치)** | **56장** | **1,785명** | **3,571명** |

브라우저 캐시까지 감안하면 두 번째 방문부터는 거의 안 받습니다.

## 저작권 표기

지도 아래 `© MapTiler © OpenStreetMap` 같은 표기가 뜹니다.
**두 곳 모두 약관에서 요구하는 것이라 지우면 안 됩니다.**
제공처를 바꾸면 표기도 자동으로 바뀝니다.

---

## 키 없이 그냥 두면

`OpenStreetMap (배포 금지)` 상태로 남습니다. 혼자 확인할 때는 되지만
학생들에게 뿌리면 안 됩니다. 설정 화면에서 이걸 고르면 경고가 한 번 더 뜹니다.
