## 1. 요약

이 앱은 **모든 정보를 이용자의 기기 안에만 저장합니다.** 서버로 전송하지 않고, 개발자도 이용자도 아닌 제3자가 열람할 수 없습니다. 계정 가입이 없고 로그인 서버도 없습니다.

이용자가 **직접 '보내기'를 누른 경우에만** 사진이 기기의 다른 앱(메시지, 카카오톡 등)으로 전달됩니다.

---

## 2. 수집하는 항목과 이용 목적

| 항목 | 수집 시점 | 이용 목적 | 저장 위치 |
|---|---|---|---|
| 학번, 이름 | 최초 실행 시 입력 | 앱 안에서 이용자를 부르는 호칭, 출석 기록 | 기기 내부 |
| 복약 인증 사진 | '오늘 약 사진 찍기'를 누를 때 | 약을 챙겨 드셨는지 스스로 확인 | 기기 내부 (최근 14일치만) |
| 복약 여부·시각 | 사진 촬영 시 자동 | 연속 기록(스트릭) 표시 | 기기 내부 |
| 걸음 수 | 걷기 미션 실행 중 | 걷기 미션 달성 여부 판정 | 기기 내부 |
| 보호자 이름·전화번호 | 통화 미션 설정 시 직접 입력 | 통화 미션에서 전화 앱 호출 | 기기 내부 |
| 통화 미션 경과 시간 | 전화 앱에서 돌아왔을 때 | 미션 달성 여부 판정 | 기기 내부 |
| 마음 신호등 선택, 채팅 입력, 게임 진행 상황 | 앱 사용 중 | 앱 기능 제공 | 기기 내부 |

### 수집하지 않는 것

- 통화 내용, 통화 상대, 통화 기록(call log) — **읽지 않습니다.** 앱을 벗어난 시각과 돌아온 시각의 차이만 계산합니다.
- 위치 정보 (GPS)
- 연락처 목록
- 기기 식별자, 광고 식별자
- 사진 보관함의 다른 사진 — 촬영한 사진만 사용합니다.

## 3. 보관 기간과 파기

- **복약 인증 사진**은 최근 **14일치만** 보관하고, 그보다 오래된 사진은 자동으로 삭제됩니다. '약을 챙겼다'는 사실과 시각만 남습니다.
- 그 외 정보는 이용자가 앱을 삭제할 때까지 기기에 남습니다.
- **앱을 삭제하면 모든 정보가 함께 지워집니다.** 별도의 삭제 요청 절차가 필요 없으며, 앱을 지운 뒤에는 어디에도 자료가 남지 않습니다.

---

## 4. 제3자 제공

이 앱은 수집한 정보를 제3자에게 제공하지 않습니다. 다만 아래 두 가지는 이용자의 기기가 외부와 통신하는 경우입니다.

### 4-1. 이용자가 직접 선택하는 공유

복약 인증 화면의 **'가족에게 보내기'** 를 눌렀을 때만, 기기의 공유 기능을 통해 이용자가 고른 앱과 상대에게 사진이 전달됩니다. 누르지 않으면 사진은 기기 밖으로 나가지 않습니다. 전달된 뒤의 처리는 해당 메신저 앱의 방침을 따릅니다.

### 4-2. 외부 서비스 접속

| 대상 | 시점 | 전달되는 정보 |
|---|---|---|
| Google Fonts (`fonts.googleapis.com`) | 앱 실행 시 글꼴을 내려받을 때 | IP 주소, 브라우저 정보 (Google의 방침에 따름) |
| 카카오 오픈채팅 | 이용자가 '상담 채널 보기'를 눌렀을 때만 | 해당 서비스의 방침에 따름 |
| 전화 앱 | 이용자가 통화 버튼을 눌렀을 때만 | 전화번호 (통신사 기록) |

> **개선 예정:** Google Fonts는 글꼴 파일을 앱에 포함시켜 외부 접속을 없앨 계획입니다. 반영되면 이 항목은 삭제됩니다.

## 5. 채팅 기능에 대하여

앱 안의 '제록이' 대화 기능은 **이용자의 기기 안에서만 동작하는 규칙 기반 응답**입니다. 입력한 내용은 어떤 서버로도 전송되지 않으며, 인공지능 학습에 사용되지 않습니다.

위기 신호로 볼 수 있는 표현이 감지되면 상담 전화 안내를 화면에 띄웁니다. 이 판단 역시 기기 안에서 이루어지며, 감지 사실이 외부에 통보되지 않습니다.

> **제록이는 상담사가 아닙니다.** 전문적인 진단이나 치료를 대신하지 않습니다.

| 권한 | 용도 | 거부해도 되는지 |
|---|---|---|
| 카메라 | 복약 인증 사진 촬영 | 예. 거부하면 사진 인증 기능만 사용할 수 없습니다. |
