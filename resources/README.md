# 아이콘 · 스플래시 원본

이 폴더에 아래 두 파일을 넣고 `npm run assets` 를 실행하면, Android와 iOS가 요구하는
모든 해상도(mdpi ~ xxxhdpi, adaptive icon, App Store 1024px 등)가 자동 생성되어
`android/` 와 `ios/` 안에 배치됩니다.

| 파일명 | 크기 | 형식 | 요건 |
|---|---|---|---|
| `icon.png` | 1024 × 1024 | PNG | 투명 배경 없이 꽉 채울 것. 모서리 둥글리기는 OS가 알아서 합니다 — **직접 둥글게 깎지 마세요.** |
| `splash.png` | 2732 × 2732 | PNG | 정사각형. 기기마다 잘리는 범위가 달라서, **가운데 1200 × 1200 안**에만 로고를 두세요. |

선택 사항 (다크 모드용):

| 파일명 | 크기 |
|---|---|
| `icon-foreground.png` | 1024 × 1024 (Android 적응형 아이콘 전경) |
| `icon-background.png` | 1024 × 1024 (Android 적응형 아이콘 배경) |
| `splash-dark.png` | 2732 × 2732 |

---

## 현재 상태 — 원본이 필요합니다

`www/assets/logo.jpg` 는 **160 × 160** 이고, `www/assets/splash.jpg` 는 **800 × 1422** 입니다.
둘 다 요구 크기에 한참 못 미칩니다.

- 160 → 1024 는 6.4배 확대라 심하게 뭉개집니다. Apple은 저해상도 아이콘을 **심사에서 반려**합니다.
- 스플래시도 세로형이라 정사각형 규격에 맞지 않습니다.

**제록이 캐릭터 원본 파일**(일러스트레이터 `.ai`, 포토샵 `.psd`, 또는 고해상도 PNG)을
학생복지과에서 받아 위 규격으로 내보내 주세요. 벡터 원본이 있으면 어떤 크기로든 깨끗하게 뽑을 수 있습니다.

> 임시로 확인만 하고 싶다면 아무 1024×1024 PNG나 넣어도 빌드는 통과합니다.
> 다만 **스토어 제출 전에는 반드시 진짜 원본으로 교체해야 합니다.**

## 배경색

`package.json` 의 `assets` 스크립트가 스플래시·아이콘 여백을 앱의 하늘색(`#4fc3f7`)으로 채웁니다.
바꾸려면 `package.json` 의 `--iconBackgroundColor`, `--splashBackgroundColor` 값을 수정하세요.
