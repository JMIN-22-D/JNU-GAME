# 인생네컷 — 부스 로컬 서버 (노트북 + ngrok + 아이패드)

## 준비물 (이 PC 에 아직 없음 — 먼저 설치)

1. **Node.js** — https://nodejs.org 에서 LTS 설치
2. **ngrok** — https://ngrok.com 가입 후 다운로드, `ngrok config add-authtoken <토큰>` 한 번 실행

## 실행 (행사 당일)

```
1) 이 폴더에서   npm install        (최초 1회만)
2)               npm start          (서버가 3000 포트에서 뜬다)
3) 새 창에서     ngrok http 3000
4) ngrok 이 보여주는 https 주소를 아이패드 사파리로 연다
5) 공유 버튼 → 홈 화면에 추가  → 전체화면 키오스크로 사용
```

**서버 창을 끄지 마세요.** 발급된 QR 은 서버 메모리에 있어서, 재시작하면 아직
안 받아간 사진의 QR 이 모두 무효가 됩니다.

## 반드시 https 로 접속

iOS 사파리는 https 가 아니면 카메라를 열지 않습니다. ngrok 주소는 https 이므로
그대로 쓰면 됩니다. `http://localhost:3000` 은 노트북에서 확인할 때만 쓰세요.

## ngrok 무료 요금제 주의

무료 플랜은 브라우저로 처음 접속할 때 **"You are about to visit..." 경고 페이지**를
한 번 띄웁니다. 방문객이 QR 을 찍으면 이 화면을 먼저 보고 **Visit Site** 를 눌러야
사진 페이지로 넘어갑니다.

- 부스 안내문에 "안내 화면이 뜨면 Visit Site 를 눌러주세요" 라고 적어두는 것을 권합니다.
- 유료 플랜이나 고정 도메인을 쓰면 이 화면이 없어집니다.
- ngrok 주소는 켤 때마다 바뀝니다. 코드에 하드코딩하지 않고 요청 헤더에서 읽으므로
  주소가 바뀌어도 수정할 것은 없습니다. 다만 **아이패드는 새 주소로 다시 열어야** 합니다.

## 동작 방식

| 경로 | 하는 일 |
|---|---|
| `POST /api/upload` | 완성된 사진을 받아 `uploads/` 에 저장하고 일회성 토큰 발급 |
| `GET /d/<토큰>` | QR 을 찍으면 열리는 안내 페이지. **토큰을 소모하지 않음** |
| `GET /api/download/<토큰>` | 실제 수령. **여기서 1회만 소모**, 전송 후 원본 삭제 |
| `GET /api/status` | 현재 주소와 대기 중인 사진 수 확인 |

### 왜 페이지 접속이 아니라 버튼에서 소모하는가

QR 스캐너 앱이나 카톡·인스타 인앱 브라우저가 링크를 **미리 불러오는** 일이 흔합니다.
페이지를 여는 것만으로 토큰을 소모시키면, 학생은 사진을 못 받았는데 "이미 받아감"
만 보게 되고 복구할 방법이 없습니다. 그래서 `사진 받기` 를 눌렀을 때만 소모합니다.

### 사진 보관

- 촬영 후 **30분** 뒤 자동 삭제 (`server.js` 의 `KEEP_MINUTES`)
- 받아간 사진은 **즉시 삭제**
- 토큰 사용 기록은 2시간 유지 — "이미 받아감" 과 "만료" 를 구분해 안내하기 위함

## 아이패드 카메라

기본은 라이브 미리보기(`getUserMedia`)입니다. 15초 타이머, 8연속 촬영, 되돌리기가
모두 여기서 동작합니다.

카메라가 열리지 않는 경우에만 화면에 **`아이패드 카메라로 한 장씩 찍기`** 버튼이
나옵니다. 이건 `capture="user"` 를 쓴 대비책으로, 앨범이 아니라 전면 카메라가 바로
뜨고 8장이 찰 때까지 반복해서 띄웁니다.

> 라이브 미리보기가 정상 동작한다면 이 버튼은 보이지 않습니다. 그게 정상입니다.
> `capture` 방식은 한 장씩 기본 카메라 앱을 거치므로 타이머·연속촬영을 쓸 수 없습니다.

## 손봐야 할 만한 곳

- `server.js` `KEEP_MINUTES` — 사진 보관 시간
- `server.js` `PORT` — 포트 (ngrok 명령의 포트도 같이 바꿀 것)
- 토큰은 8자리입니다. UUID(36자)를 쓰면 QR 이 촘촘해져 인식률이 떨어져서 짧게 했습니다.
