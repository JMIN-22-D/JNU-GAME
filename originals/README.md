# 원본 보관함

디자이너에게 받은 프레임·로고 **원본 파일**을 여기에 옮겨 둡니다.

앱이 실제로 쓰는 파일은 변환본입니다.

| 종류 | 원본 (여기) | 변환본 (앱이 쓰는 것) |
|---|---|---|
| 프레임 | `간호대학 인생네컷 4컷.png` | `assets/frames/ganho-4cut.jpg` |
| 로고 | `간호대학.png` | `assets/logos/ganho.png` |

## 왜 남겨두나

- 변환본은 JPG(품질 88)라 원본보다 화질이 조금 낮습니다
- 나중에 캔버스 규격이 바뀌면 원본에서 다시 변환해야 합니다
- 디자인 수정 요청 시 원본이 있어야 비교가 됩니다

## 넣는 법

프레임·로고 원본을 **프로젝트 폴더**에 넣고 적용을 요청하면,
변환 후 이 폴더로 옮겨집니다.
